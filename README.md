# MA2014 Visual Lab

Interactive, visual revision site for **MA2014 Differential Equations** (University of Moratuwa, B.Sc. Engineering, Semester 3).

**Live site:** https://nimsara-uom.github.io/MA2014-visual-la/

## What's inside

| Chapter | Topics |
|---|---|
| 1 · Laplace transform | shifting theorems, unit step, Dirac delta, convolution, ODEs, RLC circuits, transfer functions |
| 2 · Fourier series | even/odd, Dirichlet, half-range, Parseval, complex form, live harmonic builder |
| 3 · PDEs | classification, separation of variables, heat, wave and Laplace equations |
| 4 · Series solutions | ordinary points, Frobenius method, Bessel and Legendre |
| 5 · Fourier transform | transform pairs, properties, solving PDEs on infinite domains |

Also included: past-paper solutions (2023–2025 finals), a printable formula sheet, quizzes, progress tracking and a light/dark theme toggle.

## Run locally

No build step. Open `index.html` in a browser. Maths is rendered with KaTeX from a CDN, so an internet connection is needed the first time.
