(a)(i) Prove \(\mathcal L\{f/t\}=\int_s^\infty F\,ds\) · (a)(ii) Prove \(\mathcal L\{\int_0^tf\}=F/s\) · 10 marks
\(\int_s^\infty F(p)dp=\int_s^\infty\int_0^\infty f(t)e^{-pt}dt\,dp=\int_0^\infty f(t)\left[\frac{-e^{-pt}}{t}\right]_{p=s}^{\infty}dt=\int_0^\infty\frac{f(t)}te^{-st}dt\) ∎
\(g=\int_0^tf\): \(g(0)=0\) and \(g'=f\). So \(F=\mathcal L\{g'\}=sG-g(0)=sG\), which gives \(G=F/s\) ∎
(b)(i) \(\mathcal L\{\int_0^{t/2}\frac{1-e^{-2x}}{x}dx\}=\frac{\ln(1+1/s)}s\) · (b)(ii) \(\int_0^\infty\int_0^te^{-t}\frac{\sin u}{u}du\,dt=\frac\pi4\) · 10 marks
\(\mathcal L\{\frac{1-e^{-2t}}{t}\}=\int_s^\infty(\frac1p-\frac1{p+2})dp=\ln\frac{s+2}{s}\).
\(g(t)=\int_0^t\): \(G=\frac1s\ln(1+\frac2s)\). Then \(g(t/2)\): \(\mathcal L=2G(2s)=\frac{\ln(1+1/s)}{s}\) ∎
The double integral is \(\mathcal L\{g\}(1)\) with \(g=\int_0^t\frac{\sin u}udu\). \(\mathcal L\{\frac{\sin t}t\}=\tan^{-1}\frac1s\), so \(\mathcal L\{g\}=\frac1s\tan^{-1}\frac1s\). At \(s=1\) this is \(\frac\pi4\) ∎
(c) LR circuit, \(L=1,R=1,V=\int_0^te^{2u}\sin3u\,du\), \(I(0)=0\) · 5 marks
\((s+1)I(s)=\frac{3}{s((s-2)^2+9)}\)
\(I(s)=\frac{3/13}{s}-\frac{1/6}{s+1}-\frac{5(s-2)+3}{78((s-2)^2+9)}\)
\(I(t)=\frac3{13}-\frac16e^{-t}-\frac{e^{2t}}{78}(5\cos3t+\sin3t)\)

Q2 Series solutions 25 marks

Lesson 4.1–4.3 → (the Frobenius engine has this equation)

(a) Explain ordinary and regular singular points · 5 marksFor \(P_0y''+P_1y'+P_2y=0\) with polynomial coefficients: \(x=a\) is ordinary if \(P_0(a)\ne0\). It is regular singular if \(P_0(a)=0\) but \((x-a)\frac{P_1}{P_0}\) and \((x-a)^2\frac{P_2}{P_0}\) are analytic (finite limits) at \(a\).
(b)(i) \(x(1-x)y''+(3x-1)y'+y=0\) near 0 · 10 marks
\(xP_1/P_0=\frac{3x-1}{1-x}\to-1\) and \(x^2P_2/P_0\to0\), so x = 0 is regular singular. Take \(y=\sum a_nx^{n+m}\).
Lowest power \(x^{m-1}\): \(a_0[m(m-1)-m]=0\), so \(m^2-2m=0\) and \(m=0,2\) (Case 3).
Recurrence: \(a_{k+1}(k+m+1)(k+m-1)=a_k\big[(k+m)^2-4(k+m)-1\big]\).
\(m=2\): \(a_{k+1}=\frac{k^2-5}{(k+3)(k+1)}a_k\), giving \(y_1=x^2\left(1-\frac53x+\frac56x^2-\cdots\right)\).
\(m=0\): at \(k=1\) you get \(0\cdot a_2=-4a_1\) but \(a_1=a_0\ne0\). Contradiction, so a log term is needed: \[y_2=-2y_1\ln x+1+x-\tfrac{40}9x^3+\cdots,\qquad y=c_1y_1+c_2y_2\]
(b)(ii) \((x+1)y''-(x+1)^2y=0\) near −1 · 10 marks
Divide by \(x+1\) and let \(t=x+1\): \(y''-ty=0\). Then \(t=0\) is an ordinary point.
\(\sum(n+2)(n+1)a_{n+2}t^n=\sum a_{n-1}t^n\Rightarrow a_2=0,\ a_{n+2}=\frac{a_{n-1}}{(n+2)(n+1)}\).
\(y=a_0\left[1+\frac{(x+1)^3}{6}+\frac{(x+1)^6}{180}+\cdots\right]+a_1\left[(x+1)+\frac{(x+1)^4}{12}+\frac{(x+1)^7}{504}+\cdots\right]\)

Q4 Fourier series and Parseval 25 marks

Lesson 2.3, 2.6, 2.8 → (presets "1 + x" and "2x − 1")

\(f=1+x\) on \((-\pi,\pi)\). \(a_0=\frac1\pi\int(1+x)=2\). \(a_n=\frac1\pi\int(1+x)\cos nx=0\), since the \(x\cos nx\) part is odd and \(\int\cos nx=0\).
\(b_n=\frac1\pi\int x\sin nx\,dx=\frac{2(-1)^{n+1}}{n}\). So \(1+x=1+2\sum\frac{(-1)^{n+1}}{n}\sin nx\).
Parseval with \(l=\pi\): \(\frac1\pi\int_{-\pi}^{\pi}(1+x)^2dx=\frac1\pi\left(2\pi+\frac{2\pi^3}3\right)=2+\frac{2\pi^2}3\).
\(=\frac{a_0^2}2+\sum b_n^2=2+4\sum\frac1{n^2}\), so \(\sum\frac1{n^2}=\frac{\pi^2}6\) ∎
\(g=2x-1\) on \((0,1)\), cosine series with \(\ell=1\): \(a_0=2\int_0^1(2x-1)dx=0\).
\(a_n=2\int_0^1(2x-1)\cos n\pi x\,dx=\frac{4((-1)^n-1)}{n^2\pi^2}\). So \(2x-1=-\frac8{\pi^2}\sum_{n\,odd}\frac{\cos n\pi x}{n^2}\).
Put \(x=0\), where the even extension is continuous: \(-1=-\frac8{\pi^2}\sum_{n\ge0}\frac1{(2n+1)^2}\), so \(\sum\frac1{(2n+1)^2}=\frac{\pi^2}8\) ∎

Q1 Dirac delta and Laplace applications 25 marks

Lesson 1.6 → (δₙ animation)

\(\int_0^\infty f\delta_n=n\int_{a-1/2n}^{a+1/2n}f\,dt=f(c_n)\) by the mean value theorem, with \(c_n\) in the interval. As \(n\to\infty\), \(c_n\to a\), so the limit is \(f(a)\) by continuity.
Put \(f=e^{-st}\): \(\mathcal L\{\delta(t-a)\}=e^{-as}\).
\(y''+y=\delta(t-3)\) with zero ICs: \((s^2+1)Y=e^{-3s}\), so \(y=\sin(t-3)\,u(t-3)\).
\(y''''=-\delta(x-2)\). Transform: \(s^4Y-s^3y(0)-s^2y'(0)-sy''(0)-y'''(0)=-e^{-2s}\).
With \(y(0)=y''(0)=0\) and \(y'(0)=y'''(0)=1\): \(Y=\frac1{s^2}+\frac1{s^4}-\frac{e^{-2s}}{s^4}\), so \(y=x+\frac{x^3}6-\frac{(x-2)^3}6u(x-2)\).
But that gives \(y(4)\ne0\), which contradicts \(y(L)=0\). The figure shows a simply supported beam. Treat \(y'(0)=A\) and \(y'''(0)=B\) as unknowns: \(y=Ax+\frac{Bx^3}6-\frac{(x-2)^3}6u(x-2)\). Then \(y''(4)=4B-2=0\Rightarrow B=\frac12\), and \(y(4)=4A+4=0\Rightarrow A=-1\). \[\boxed{y=\frac{x^3}{12}-x-\frac{(x-2)^3}{6}u(x-2)}\] Mid-span deflection \(y(2)=-\frac43=-\frac{FL^3}{48EI}\) ✔. Write both versions in the exam and state your interpretation.

Q3 Wave equation 25 marks

Lesson 3.7 → (string simulator has both cases)

\(y=XT\Rightarrow X''+p^2X=0\) and \(T''+c^2p^2T=0\). Ends fixed, so \(p=\frac{n\pi}l\): \(y=\sum\sin\frac{n\pi x}l\left(C_n\cos\frac{n\pi ct}l+D_n\sin\frac{n\pi ct}l\right)\).
\(y_t(x,0)=0\Rightarrow D_n=0\). \(y(x,0)=\sum C_n\sin\frac{n\pi x}l=200\sin\frac{4\pi x}l\Rightarrow C_4=200\), all others 0. So \(y=200\sin\frac{4\pi x}l\cos\frac{4\pi ct}l\) ∎
\(y(x,0)=0\Rightarrow C_n=0\). \(y_t(x,0)=\sum D_n\frac{n\pi c}l\sin\frac{n\pi x}l=100\sin\frac{\pi x}l\Rightarrow D_1=\frac{100l}{\pi c}\). So \(y=\frac{100l}{\pi c}\sin\frac{\pi x}l\sin\frac{\pi ct}l\).

Half-range cosine of \(x(\pi-x)\) on \((0,\pi)\): \(a_0=\frac2\pi\int_0^\pi x(\pi-x)dx=\frac{\pi^2}3\).
\(a_n=\frac2\pi\int_0^\pi x(\pi-x)\cos nx\,dx=-\frac{2(1+(-1)^n)}{n^2}\). That is \(-\frac{4}{n^2}\) for even \(n\) and 0 for odd. Writing \(n=2k\): \(-\frac1{k^2}\cos2kx\). So \(x(\pi-x)=\frac{\pi^2}6-\sum\frac{\cos2kx}{k^2}\) ∎
Parseval (half-range cosine): \(\frac2\pi\int_0^\pi x^2(\pi-x)^2dx=\frac2\pi\cdot\frac{\pi^5}{30}=\frac{\pi^4}{15}=\frac{\pi^4}{18}+\sum\frac1{k^4}\), so \(\sum\frac1{n^4}=\frac{\pi^4}{90}\).
\(f=\cos x\) on \((-\frac\pi2,0)\). A sine series needs an odd function on \((-\frac\pi2,\frac\pi2)\), so \(f=-\cos x\) on \((0,\frac\pi2)\) with \(\ell=\frac\pi2\).
\(b_n=\frac{2}{\pi/2}\int_0^{\pi/2}(-\cos x)\sin2nx\,dx=-\frac4\pi\cdot\frac{2n}{4n^2-1}\). So \(f(x)=-\frac8\pi\sum\frac{n\sin2nx}{4n^2-1}\).
The series has period \(\pi\). \(f(\pi)=f(0)\), and at 0 there is a jump between \(1\) and \(-1\), so the value is \(0\). \(f(\pi/4)=-\cos\frac\pi4=-\frac1{\sqrt2}\).
\(c_n=\frac12\int_{-1}^1e^{-x}e^{-in\pi x}dx=\frac{(-1)^n\sinh1}{1+in\pi}\), so \(e^{-x}=\sum_{n=-\infty}^{\infty}\frac{(-1)^n\sinh 1\,(1-in\pi)}{1+n^2\pi^2}e^{in\pi x}\).
